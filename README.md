# AI対話記録ツール(AiTalkLog)

## 📝 概要
　AiTalkLog は、生成AIとの会話内容を効率的に記録・整理するための支援ツールです。本ツールで作成したプロンプトを生成AIにコピー＆ペーストし、得られたレスポンスを再び本ツールへ貼り付けることで、対話の流れを見出し付きで蓄積できます。あらかじめ用意された事前プロンプトの選択や、利用する生成AIの切り替えにも対応しており、少ない操作でスムーズに対話ログを管理できることができます。  

👉 **まずはお試しください**
- **ZIP をダウンロードして AiTalkLog.exe を起動してみることをおすすめします。**
- 実際の画面を見ながら README を読むと、操作の流れがより分かりやすくなります。

## ✨ 特徴
- **対話タイトルとキーワードの自動生成**  
  会話内容からタイトルとキーワードを自動抽出し、後から読み返しやすい形で整理できます。

- **キーワード検索とタイトル一覧で高速に振り返り可能**  
  対話ごとにタイトルが付与され、キーワード検索にも対応しているため、過去ログの参照が容易です。

- **複数の事前プロンプトテンプレートを用意**  
  簡潔型・標準型・詳細型・拡張型の事前プロンプトを選択可能。  
  自分でテンプレートを追加することもできます。

- **利用する生成AIを選択可能**  
  Copilot、ChatGPT、Gemini、Claude を初期設定として用意。  
  任意の生成AIを追加することもできます。

- **同じプロンプトを複数AIで比較可能**  
  同一プロンプトを別の生成AIに適用し、レスポンス内容を比較できます。

- **レスポンス内容を VSCode で閲覧可能**  
  記録したレスポンスを VSCode でビューできます。  
  VSCode が未インストールの場合はテキストビューを利用できます。

## 🖥️ 動作環境、必要なもの
- **OS**：Windows 10 / 11  
- **ネット接続環境**：生成AIサービス利用のため必須 
- **インストール不要（ZIPを展開して exe を実行するだけ）**
- **レジストリ未使用（フォルダを削除すれば完全に消えます）**
- **生成AIサービスのアカウント**（Copilot / ChatGPT / Gemini / Claude など）
- **推奨**：Visual Studio Code（レスポンス内容のビュー用）

## 🧩 プロンプト構造（AiTalkLog の基本概念）
AiTalkLog は、生成AIとの対話を次の 3 種類のプロンプトで構成しています。

### 1. システムプロンプト（system_prompt.txt）
AI に対して「対話名・キーワード・回答者・要約・本文」を指定の形式で出力させるためのルールです。
AiTalkLog の自動抽出機能が依存しているため、内容を変更すると正しく動作しない場合があります。
必要に応じて編集できますが、初期設定のまま利用することを推奨します。

### 2. 事前プロンプト（10_prompt/*.txt）
対話の前提条件や出力スタイルを指定するためのプロンプトです。
ユーザーが自由に追加・編集できます。

### 3. 本文プロンプト
ユーザーが AI に依頼したい内容そのものです。
例：コードレビュー、文章生成、技術相談など。

この 3 層構造によって、AiTalkLog は対話内容を整理しやすくし、
タイトル生成・キーワード抽出・要約などを自動化します。

## 🗂️ 対話構造（表題と対話の関係）
AiTalkLog では、生成AIとのやり取りを次の二層構造で管理します。

### 1. 表題（Topic）
対話の大きなカテゴリを表します。
例：
- 「JavaFX の UI 設計」
- 「AI プロンプトの改善」
- 「業務日報の作成相談」

表題はユーザーが手動で作成・編集します。

### 2. 対話（Talk）
表題の中に含まれる個々の会話です。
本文プロンプトとレスポンスの内容から、
**対話名（タイトル）とキーワードが自動生成**されます。

例：
- 「【Copilot】【標準】UI レイアウトの改善案」
- 「【ChatGPT】【簡潔】プロンプトの要約生成」

この二層構造により、  
「大きなテーマ（表題）」と「個別の会話（対話）」を整理しながら蓄積できます。

## ▶️ 起動方法
1. ダウンロードした ZIP を任意のフォルダに展開します  
2. 展開したフォルダ内の **AiTalkLog.exe** をダブルクリックします  
3. 初回起動時は少し時間がかかる場合があります。
4. デュアルモニタ環境では、アプリ起動時に表示モニタを確認するダイアログが表示されます。表示したいモニタを選択して下さい。


## 🛡️ SmartScreen の警告について
初回起動時に Microsoft Defender SmartScreen が「Windows によって PC が保護されました」と表示される場合があります。  
これは **署名のない新しいアプリを一時的に止める Windows の通常動作** です。  
実行する場合は、**「詳細情報」 → 「実行」** を選択してください。

## ⚠️ 起動が遅く感じられる場合について
配布形式（exe版）の特性上、初回起動時に Windows のセキュリティチェックや  
JavaFX の初期化が行われるため、起動がやや遅くなることがあります。  
不具合ではありませんので、そのままお待ちください。  
2回目以降はより早く起動します。

## 📘 使い方

### 0. **表題を選択する（または新規作成する）**
- 対話一覧画面の操作  
- 記録したい表題（トピック）をダブルクリックして選択します。  
  続いて、対話一覧の中から記録したい対話をダブルクリックします。  
- 必要に応じて「追加」で新しい表題を作成できます。  
  新規作成した場合は、そのまま対話一覧画面が開かれます。

### 1. **事前プロンプトと生成AIの選択**
- 対話詳細画面の操作  
- 事前プロンプトを選択します。  
  - **簡潔モード**：短い要約で回答  
  - **標準モード**：要約＋詳細の見出し  
  - **詳細モード**：要約＋見出し＋詳細本文  
  - **AIおまかせ**：AIが自由な形式で回答  
- 利用する生成AIを選択します。

### 2. **本文プロンプトを作成する**
- 対話詳細画面の操作  
- 本文プロンプトを入力し、「コピー【事前プロンプト付き】」を押します。  
- プロンプトがクリップボードにコピーされるので、生成AIに貼り付けて送信します。

### 3. **生成AIのレスポンスを貼り付ける**
- 対話詳細画面の操作  
- 生成AIの回答をコピーし、レスポンス欄の「ペースト」ボタンを押します。  
- レスポンス内容から **対話名とキーワードが自動設定**され、画面上部に表示されます。  
- 「戻る」ボタンで対話一覧画面に戻ります。

### 4. **対話を保存する**
- 対話一覧画面の操作  
- コマンドラインの「保存」を押します。

### 5.補足
- 生成AIの追加：  
  `AiTalkLog起動フォルダ/00_config/ai_list.json` を編集します。
- 事前プロンプトの追加：  
  `AiTalkLog起動フォルダ/10_prompt/{追加するプロンプト名}.txt` を追加します。

## 🧩 まとめ
　AiTalkLog 自体は AI 機能を持ちませんが、生成AI（Copilot、ChatGPT、Gemini、Claude など）と組み合わせることで、その真価を発揮します。
生成AIが「回答を生成する役割」、AiTalkLogが「対話を記録・整理・比較する役割」を担うことで、プロンプト作成からレスポンス管理までの流れが途切れず、効率的に作業できます。
